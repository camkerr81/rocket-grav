# Web Theme Request

When the user asks you to build, create, or scaffold a new website or web application, you MUST explicitly ask them what visual theme or design aesthetic they would like you to use.

You should offer suggestions such as:
- **Catppuccin**
- **Dracula**
- **Cyberpunk**
- **Game Boy / Arcade**
- **Neobrutalism**
- **Glassmorphism**
- **Clean Tech**

Do not proceed with generating full styles or scaffolded UI code until the user has provided a theme preference, unless they explicitly tell you to proceed with a default theme.
