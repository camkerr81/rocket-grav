# Rule: No Emojis

Do not use emojis in any responses, explanations, documentation, commit messages, or code output.
Always use clean Unicode typographic equivalents instead (e.g. `[✓]`, `[!]`, `[x]`, `•`, `▶`, `→`, `◆`, `■`, `§`, etc.).
