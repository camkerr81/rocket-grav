---
description: "Instructions for handling Beads issues and issue closures."
---

When working on bugs, features, or any Beads (bd) issues, DO NOT use `bd close` or `bd complete` to close the issue automatically when you finish the code changes. 

The user prefers to thoroughly test the code in their environment first. 

Instead of closing the issue, leave it open and explicitly tell the user that the code is ready for them to test, and that they can close the issue (or ask you to close it) once they have verified it works.
